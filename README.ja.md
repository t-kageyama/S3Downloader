## 概要

S3 Downloader は、Amazon S3 上のファイルをできるだけシンプルにダウンロードすることを目的としたコマンドラインツールです。

高機能な S3 クライアントとは異なり、本プロジェクトはダウンロード機能に特化しています。日常的なダウンロード作業を、素早く、シンプルに、そして分かりやすく行えることを目標としています。

なぜ「Downloader」なのか？

アップロードや同期、ファイル管理などの高度な機能を備えた優れた S3 クライアントは、すでに数多く存在します。

本プロジェクトは、それらのツールを置き換えることを目的としていません。

代わりに、次の一つの目的に焦点を当てています。

Amazon S3 上の必要なファイルを、素早く、シンプルにダウンロードすること。

典型的な利用シーンは、メールやチャットで送られてきたファイルパスを指定し、コマンドラインからすぐにダウンロードすることです。

本プロジェクトの考え方は、とてもシンプルです。

* 覚えやすいインターフェースを提供する。
* ダウンロード機能に集中する。
* 高度な S3 管理機能は、専用のツールに任せる。

特徴

* 対話形式のコマンドラインインターフェース
* Amazon S3 上のファイルをダウンロード
* ディレクトリの移動 (cd, pwd)
* ファイルおよびディレクトリの一覧表示 (ls, lsr)
* ファイル名またはフルパスを指定したダウンロード
* コマンドラインオプション (-d) によるダウンロード
* 軽量でシンプル

## インストール

リポジトリをクローンします。

```
git clone ...
```

Maven を使用してビルドします。

```
mvn package
```

実行可能な JAR ファイルは target ディレクトリに生成されます。

## 設定

以下のような properties ファイルを作成します。

```properties
accessKeyId=YOUR_ACCESS_KEY_ID
secretAccessKey=YOUR_SECRET_ACCESS_KEY
bucket=your-bucket
region=ap-northeast-1
```

この例では AWS 東京リージョン (`ap-northeast-1`) を使用しています。

| プロパティ | 説明 |
| --- | --- |
| accessKeyId | AWS アクセスキー ID |
| secretAccessKey | AWS シークレットアクセスキー |
| bucket | Amazon S3 バケット名 |
| region | AWS リージョン |

Amazon S3 への接続前に、必須のプロパティがすべて設定されていることを確認します。

## 利用例

チームで以下のようなメールを受け取ったとします。

```text
設計書を更新しました。

以下のファイルをダウンロードしてください。

DOCUMENTS/SPEC_SHEETS/API_USAGE.pdf
```

ファイルをダウンロードする方法は、主に次の 3 つです。

### 1. 対話モード（ディレクトリを移動してからダウンロード）

```text
$ s3download config.properties
> cd /DOCUMENTS/SPEC_SHEETS
> dl API_USAGE.pdf
```

同じディレクトリから複数のファイルをダウンロードする場合におすすめの方法です。

### 2. 対話モード（フルパスを指定してダウンロード）

```text
$ s3download config.properties
> dl /DOCUMENTS/SPEC_SHEETS/API_USAGE.pdf
```

単一のファイルをダウンロードする場合に便利です。

### 3. コマンドラインモード

```bash
$ s3download config.properties \
    -d /DOCUMENTS/SPEC_SHEETS/API_USAGE.pdf
```

シェルスクリプトやバッチファイルなどから実行する場合に適しています。

## コマンド

| コマンド | 説明 |
| -------- | ---- |
| ls | ファイルおよびディレクトリの一覧を表示します。 |
| lsr | ファイルおよびディレクトリを再帰的に表示します。 |
| cd | カレントディレクトリを変更します。 |
| pwd | 現在のディレクトリを表示します。 |
| dl | ファイルをダウンロードします。 |
| help | ヘルプを表示します。 |
| exit | アプリケーションを終了します。 |

## 設計思想

S3 Downloader は、一つの目的をできるだけシンプルに実現することを目指して設計されています。

**Amazon S3 上の必要なファイルを、素早く、シンプルにダウンロードすること。**

## バージョン履歴

### 1.2.0
- `ls`, `lsr`に引数を追加。
- 引数が`/`で終了する場合はディレクトリとして扱います。`/`で終了しない場合は、名前が完全一致するファイル・ディレクトリをリストします。

### 1.1.0
- 上下矢印キーによる履歴ナビゲーションを追加。ただし無効コマンドやファイルダウンロード時の入力は履歴から除外。
- `cd`で、存在するディレクトリ名の先頭部分と一致する存在しないディレクトリへの移動が成功してしまう不具合を修正。

### 1.0.0
- 初期リリース
